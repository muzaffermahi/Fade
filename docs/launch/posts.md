## Show HN

**Show HN: Fade — keep talking to your coding agent while it builds**

Fade runs two agents side by side in your terminal. You talk with Fade; a separate Builder writes the
code. While one change builds, you keep going: plan the next feature, ask about the code, line up more
work. When a change lands, Fade has already saved it as a commit and re-run its checks itself, so
"checked" means Fade ran it, not that a model said tests pass. It only stops you for taste questions.
No modes or hotkeys: say yes, undo that, show me, stop. Demo with no key:
`npx @muzaffermahi/fade --demo`. [GIF] [project link]
